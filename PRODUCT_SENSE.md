# PRODUCT_SENSE

Moradin's Forge gives coding agents repeatable local reflexes for repo
adoption. The product value is fewer repeated planning tokens, clearer consent
gates, safer sidecar deployment, and deterministic validation after changes.

The primary audience is an agent operating on behalf of a developer. Human
operators remain in control of approval, host tool installation, publishing, and
any root workflow patch.
