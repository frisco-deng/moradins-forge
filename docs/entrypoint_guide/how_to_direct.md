# How To Direct An Agent

Send the agent to Forge with this intent:

1. Inspect Forge.
2. Inspect the target repo.
3. Explain what will be written.
4. Ask before applying.
5. Verify after applying.

Use `Harness/entrypoints/forge_agent_handoff.md` for the copy/paste prompt.
