# Day 1 Onboarding Runbook

## Purpose

- Execute the first scoped cycle with full governance artifacts and gate discipline.

## Checklist

- [ ] Route work to one phase/stage/cycle and create/update plan artifact.
- [ ] Implement scoped changes with deterministic validation evidence.
- [ ] Update loop state/changelog/capability artifacts for the cycle.
- [ ] Stop at human gate and record explicit continuation decision.
- [ ] Archive update/upgrade outputs when applicable.
