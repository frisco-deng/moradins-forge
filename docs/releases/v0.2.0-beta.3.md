# Moradin Forge v0.2.0 Beta 3

## Summary

Beta.3 makes Forge a standalone universal-agent workstation baseline. Point an
agent at the README to get bounded discovery, a practical tooling plan,
separate approvals, transactional adoption and upgrades, and compact
context-preserving helpers without a private `.templates` dependency.

## Highlights

- Adds repeatable, approved multi-workspace onboarding and repository
  discovery without broad source or home-directory crawling.
- Adds the adaptive practical-full developer, security, supply-chain,
  container, release, and token-efficiency catalog.
- Permits exact-digest-approved user-level installs and produces reviewable
  user-run Bash or PowerShell for privileged packages.
- Adds official-source resolution with a 24-hour invocation-time cache,
  execution receipts, rollback, and checksummed offline bundles.
- Adds independently approved, marker-owned `AGENTS.md` and `CLAUDE.md`
  integration with lowercase-file warnings.
- Adds standalone context primer, state, repository brief, rerun advice,
  checkpoints, and sanitized local efficiency counters.
- Adds transactional V1/V2 sidecar upgrades with stale-plan protection,
  atomic cutover, byte-identical failure recovery, and one retained
  predecessor.
- Adds native Linux, macOS, and Windows contract validation while preserving
  the existing GitHub Free CI/security/dependency-submission split.

## Runtime Notes

- Forge core requires Python 3.12 or newer.
- The optional browser workbench requires Node.js 24 or newer.
- Tool update checks occur only when Forge runs and cached metadata is stale.
- There is no background updater.

## Release Boundary

This is a prerelease candidate, not a production-readiness claim. Signing,
production readiness, release-candidate manifest, platform signing, and
production promotion remain deferred human-gated lanes.
