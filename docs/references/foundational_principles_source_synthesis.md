# Foundational Principles Source Synthesis

Forge adapts common agent-engineering lessons into a small public contract:

- keep instructions short and discoverable,
- turn repeated decisions into deterministic commands,
- require consent before mutation,
- keep local integration reversible,
- verify generated artifacts before handoff.
