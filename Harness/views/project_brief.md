# Project Brief

Moradin's Forge provides:

- an agent-first local integration flow,
- a consent-gated `.moradins-harness/` sidecar,
- adaptive snippets for common repo tooling,
- digest-bound tooling plans and verified user-level execution,
- user-run privileged scripts and checksummed offline bundles,
- independently approved agent guidance blocks,
- compact context and rerun helpers,
- transactional sidecar upgrades,
- deterministic verification after adoption.
